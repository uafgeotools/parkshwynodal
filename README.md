# Denali Nodal Seismic Data along the Parks Highway (Feb-March 2019)
## Bella Seppi

## University of Alaska Fairbanks
![stations](/input/sample_image.png)


Between 2019-02-11 and 2019-03-26 a set of 303 Fairfield Nodal 3C 5Hz sensors were deployed along the Parks Highway in south-central Alaska between the towns of Nenana (north) and Trapper Creek (south). A map of these can be found from the [FDSN network page](http://ds.iris.edu/gmap/#network=ZE&maxlat=64.8752&maxlon=-147.5002&minlat=62.227&minlon=-151.5871&drawingmode=box&planet=earth).
